创造服挂在同一条群组入口上，从 [登录大厅](../Lobby.md) 走对应传送门，或使用 `/server <后端ID>`。这些子服**不**和生存组同步背包，也不走西瓜币商店。

需要搭机器、测机制时用虚空实验室；需要造船、摆场景时用船坞。

## 现开

- **[虚空实验室](./VoidLab.md)** — 创造模式虚空世界，用于机器测试与建筑验证
- **[船坞](./Shipyard.md)** — 和平建造向（造船 / 摆场景）
